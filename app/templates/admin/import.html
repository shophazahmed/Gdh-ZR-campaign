Import voters

Upload the voter files, or the whole folder as one .zip (photos included). Excel (.xlsx, .xls), .csv and PDF voter lists are read (photos printed in a PDF are taken from it); separate photos can be .jpg, .png or .webp, named after the ID card (e.g. A123456.jpg).

More than one file? When the same ID card is in two files, the file whose name comes first wins. Start the names with a number to set the order, newest first: 1 voters 2026.xlsx, 2 party list.csv, 3 old list.xlsx.

Gadhdhoo file names

If one of these Gadhdhoo files is uploaded, the four are read in this fixed order instead:

  1. Gahdhdhoo.2026 — newest, with photos
  2. gadhoo-new voters
  3. Gadhdhoo (updated Party list MPD ) — the current MDP list: everyone on it is MDP; MDP voters missing from it become OTHER
  4. final_cleaned_gadhdhoo_updated_party — oldest

A file name may have extra words after these, e.g. gadhoo-new voters - sex.csv.
